# Maartens Top 100

Mijn persoonlijke muzieklijsten sinds 2012: elke top 100 op een eigen pagina met stijgers, dalers en nieuwe binnenkomers, de Top Aller Tijden, mijn Spotify-jaarlijsten, artiestenpagina's met concerten (setlist.fm) en records.

De hele site staat in één bestand: `index.html`. De gegevens zitten daarin (`const D = …`).

## Bijwerken
Nieuwe lijst of andere wijziging? Vervang `index.html` door de nieuwe versie. Claude maakt die uit *Totaal overzicht top 100.xlsx* en de Spotify-exports.

## Wat werkt alleen in deze websiteversie
- Albumhoezen, jaartallen en fragmenten (iTunes), bandlogo's en artiestinformatie (Wikipedia/Wikidata).
- Een Spotify-speler onderin de pagina bij nummers met een bekende Spotify-link. Ben je in deze browser ingelogd bij Spotify, dan speelt het hele nummer, anders een fragment.
- Opslaan (bijv. een concept op de pagina *Nieuwe lijst*) gebeurt alleen in je eigen browser.
